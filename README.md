# Annual Sales Report for Electronic Items

This project presents an interactive **Power BI dashboard** that analyzes the annual sales performance of electronic items. The report provides clear insights into sales trends, product-wise performance, regional distribution, and key business metrics through structured and interactive visualizations.

The repository is intended for data analysis demonstration, business intelligence practice, and portfolio presentation.

---

## Project Overview

The Annual Sales Report for Electronic Items analyzes historical sales data to help understand overall business performance. Using Power BI, the project transforms raw sales data into meaningful insights that support data-driven decision-making.

The dashboard allows users to explore trends, compare categories, and evaluate performance across regions and time periods.

---

## Key Features

- Annual sales overview
- Product category breakdown (TVs, Laptops, Mobiles, and others)
- Region-wise and store-wise sales performance
- Monthly sales trends and comparisons
- Revenue, units sold, and profitability insights
- Interactive filters and drill-down capabilities

## How to Use

1. Download or clone the repository:
```text
git clone https://github.com/mdasharaf07/Annual-Sales-Report-for-Electronic-Items.git
```

2. Open the `sales report.pbix` file using Power BI Desktop.
3. Explore the dashboard using slicers, filters, and visuals.
4. Modify or extend the report using your own dataset if required.

## Limitations

- Does not connect to a live or real-time data source
