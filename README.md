# 📊 Annual Sales Report for Electronic Items
This project presents a detailed Power BI dashboard showcasing the annual sales performance of electronic items. It provides insights into sales trends, product-wise performance, revenue distribution, and key business metrics through interactive visualizations.

# 📸 Dashboard Preview
![Sales Dashboard Preview](https://i.postimg.cc/K8xynTFT/preview.jpg)

# 📁 File Included
sales report.pbix – Power BI project file containing all data visualizations and reports

# 📌 Key Features
📆 Annual sales overview

🖥️ Product category breakdown (TVs, Laptops, Mobiles, etc.)

🌍 Region-wise and store-wise sales performance

📈 Sales trends and monthly comparisons

🧾 Revenue, units sold, and profitability insights

🔍 Interactive filters and drill-down capabilities

# 🛠️ Tools Used
Power BI Desktop

Data modeling, DAX measures, and visual analytics

# 🚀 How to Use
Open the .pbix file using Power BI Desktop.

Explore the report using slicers, filters, and visuals.

Customize it with your own dataset if needed.

# 💡 Possible Extensions
Connect to a live database or Excel source

Add forecast analytics using built-in AI visuals

Embed in a website or SharePoint for stakeholder access
